Сборка наборов — КМ-трекинг

Логика: сканируем товар → система по GTIN определяет набор и нужный состав → сканируем оставшиеся товары → сканируем агрегационный код набора (закрывает набор, кладём в короб) → повторяем, пока короб не заполнен → сканируем агрегационный код короба (закрывает короб) → сканируем ШК паллеты, когда на неё выложены короба (закрывает паллету). Каждый склад — независимый контур, коды уникальны глобально.

Формат — как в примере от Таможенного отдела: Название набора / Код идентификации набора / Наименование товара / Код маркировки. Технические поля (короб, паллета, склад, время) в выгрузку не входят — хранятся во внутренней БД для разбора инцидентов.
