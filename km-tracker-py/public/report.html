Отчёт для ТО

Формат выгрузки: Код идентификации набора / Номер набора / Наименование товара / Код маркировки. Символ GS (ASCII 29) в таблице показан как [GS], а в файле записан настоящим символом. В файл входят только товары с КМ из закрытых наборов.

GS — невидимый разделитель между полями кода. В Excel, Блокноте и при копировании в чат он не виден и может пропадать, поэтому код «выглядит» слитным — в файле при этом он есть (в таблице ниже он показан как [GS]).
